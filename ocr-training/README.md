# 验证码本地 OCR 训练（本地专用，不推送 GitHub）

辅助插件（urpppp）的验证码本地识别模型。**样本与模型在 `.gitignore` 中排除，不会推送到 GitHub**；训练脚本计入 git。

## 当前状态（2026-08 最终版）

**统一认证（scu-id）——已完成并集成，可用**

- 500 张样本 + 210 张人工标注，质心模板模型
- 留出验证整图 100%，已集成进辅助插件（本地优先，线上兜底）
- 与 scu-plus 的 scu_ocr_lite_dart 同源算法

**教务系统（zhjw）——本地 OCR 模型（71KB 部署版）**

- 管线：HSV 红色掩码 → k-means 切割 4 字符 → 32×32 单字符 CNN → int16 量化
- 模型：深度可分离微型 CNN（16/32/64/64 通道），27 类
- **模型大小：71.2KB**（int16 + base64，`model/zhjw-char-tiny71-int16.json`）
- 独立验证（双视图可靠标签，多批次）：整图 ~81-88%，字符 ~95%
  - 32×32 微型（71KB）：约 81%
  - 48×48 微型（201KB）：约 87%（保留备选）
- 部署：`zhjw-ocr.js`（HSV 掩码 + k-means 切割 + int16 CNN 推理，纯 JS 无依赖）

| 方案 | 体积 | 整图 | 说明 |

| **32×32 微型（部署版）** | **71KB** | **~81%** | 体积最优 |

## 关键技术结论

1. **HSV 红色掩码是教务预处理正解**（hue∈[170,179]∪[0,12]，sat≥50，cv2 语义），免疫黑线。
2. **k-means 聚类切割**（精准贴合字符 ~23px）优于固定窗口（31px 混入相邻字符）。
3. **标签质量是最大瓶颈**：read 单视图标注噪声大（m/n/h 系统误标），双视图投票 + 单张复核可消除；可靠标签下模型真实水平比单视图标签高 6-8 个百分点。
4. **质心模板不适用教务**（统一红色无法颜色聚类），CNN 是正路。
5. **深度可分离卷积**：参数 26.7K（int16 71KB），与紧凑 CNN（255K）比缩小 9.6 倍。
6. **int16 > int8**：微型模型权重小，int8 量化误差使 logits 翻转；int16 几乎零损失。
7. **JS 推理必须复现 cv2 语义**：HSV 掩码 H 用 uint8 截断、BGR 通道序、深度可分离 ReLU 只在 pw 后。
