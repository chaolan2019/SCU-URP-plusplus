# 验证码本地 OCR 训练（本地专用，不推送 GitHub）

辅助插件（urpppp）的验证码本地识别模型。**样本与模型在 `.gitignore` 中排除，不会推送到 GitHub**；训练脚本计入 git。

## 当前状态（2026-08 清理后）

**统一认证（scu-id）——已完成并集成，可用**

- 500 张样本 + 210 张人工标注
- 方案：颜色量化分割（每字符一色）+ 饱和度过滤（排除灰色斜线）+ 8×6 二值 + 宽高比（AR_WEIGHT=25）质心模板
- 留出验证整图 100%（40/40），已集成进辅助插件（本地优先，线上兜底）

**教务系统（zhjw）——已清理，方案待定**

教务验证码（红色扭曲字符 + 黑色曲线涂抹 + 笔画粘连）经多轮实验（模板匹配 / CNN / 线上 OCR 自动标注 / 红色提取纯净图）均未达可用水平，相关样本与脚本已清理。核心障碍：黑线涂抹造成笔画信息损失、相似字形（b/d、m/n、l/1 等）导致标注歧义。

## 目录

| 路径 | 内容 |
|------|------|
| `scu-id/` | 统一认证验证码样本（80×26，4 位彩色字符） |
| `labels/scu-id.json` | 人工标注（210 张） |
| `model/scu-id.json` | 质心模板模型（32 类，内嵌进辅助插件） |
| `collect-scu-id.mjs` | 样本收集（接口直抓，可续拉） |
| `train.mjs` | 训练（颜色量化分割 + 质心模板，留出验证） |
| `eval.mjs` | 识别验证（输入图片路径输出 4 位码） |
| `contact.mjs` | 拼图标注辅助工具 |

## 用法

```bash
node collect-scu-id.mjs 500   # 收集（已存在自动跳过）
node contact.mjs scu-id 1 10  # 生成标注拼图
node train.mjs scu-id --full  # 全量训练输出模型
node eval.mjs <图片路径>       # 识别一张验证码
```
