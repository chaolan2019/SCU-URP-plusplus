# 验证码本地 OCR 训练（本地专用，不推送 GitHub）

辅助插件（urpppp）的验证码本地识别模型训练目录。**样本与模型在 `.gitignore` 中排除，不会推送到 GitHub**；训练脚本计入 git。

## 目录

| 路径 | 内容 |
|------|------|
| `zhjw/001.jpg ~ 100.jpg` | 教务系统验证码样本（180×60，红色扭曲字符 + 黑色曲线干扰） |
| `scu-id/001.png ~ 500.png` | 统一认证验证码样本（80×26，4 位彩色字符 + 斜线 + 噪点） |
| `labels/*.json` | 标注结果（样本号 → 字符内容） |
| `model/*.json` | 训练产物：k-means 多模板模型（当前 scu-id 用 210 张训练） |
| `contact/*.png` | 拼图标注辅助图（10 张/批） |

## 收集

```bash
node collect-zhjw.mjs 100    # 教务系统：http://zhjw.scu.edu.cn/img/captcha.jpg（免登录）
node collect-scu-id.mjs 500  # 统一认证：验证码接口（已存在文件自动跳过，可续拉）
```

## 训练与验证

```bash
node train.mjs scu-id          # 默认留出后 20% 作验证，报告字符级与整图准确率
node train.mjs scu-id --full --k=5   # 全量训练输出最终模型（每类 5 个质心模板）
node train.mjs zhjw --dry      # 教务：分割统计（教务当前未达标，见下）
node eval.mjs scu-id <图片路径> # 用模型识别一张验证码
node contact.mjs scu-id 1 10   # 生成 1-10 号的拼图标注图
```

## 关键参数（逆向结论）

| 站点 | 尺寸 | 位数 | 字符集 | 干扰 |
|------|------|------|--------|------|
| 教务 zhjw | 180×60 | 4~5 | 字母+数字 | 黑色曲线涂抹，红字 |
| 统一认证 scu-id | 80×26 | 4 | 字母+数字 | 灰色斜线 + 彩色噪点，每字符独立颜色 |

## 训练结论（v2 复刻 scu-plus 方法，2026-08 实测）

统一认证（scu-id）：**颜色量化分割（每字符一色 → top-4 颜色聚类）+ 饱和度过滤（sat≥10 排除灰色斜线）+ 48 像素 8×6 二值 + 宽高比（AR_WEIGHT=25）质心模板**。

- 标注 210 张，**留出验证整图准确率 100%（40/40）**，训练集自检 99.9%
- 210 张中 200 张可分割识别，10 张因字符饱和度不足漏检（不误检）
- 训练集样本实测全部正确（kcxq / 4mg8 / bh9x / 6df5）
- 关键适配：scu-plus 原版用精确去灰线（#6f6e70），我们验证码是灰色斜线干扰，改为饱和度过滤

教务（zhjw）：红色字符被黑线切碎 + 粘连，未达可用水平，未继续投入。
