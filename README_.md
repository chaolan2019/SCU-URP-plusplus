## 这是什么

`urpppp.user.js` 是 **SCU URP++ 主脚本的可选扩展**，不修改主脚本文件。

| 项目 | 内容 |
|------|------|
| 文件 | `urpppp.user.js`（独立安装） / `urpppp.plugin.js`（被主插件装载） |
| 当前版本 | **1.5.3** |
| 依赖 | 主脚本 `urppp.user.js`（设置入口挂在主脚本 **系统设置** 选项卡） |
| 作者 | `Chao_Lan, Hanako` |

## 安装

**方式一（推荐）：在主插件里直接装载**

主插件 v1.9.0 起，无需单独安装油猴脚本——打开 主插件 设置 → 系统设置 → 辅助插件 → 点「**装载辅助插件**」，主插件会自动下载并装载，装载后即可在设置里使用登录助手 / 评教助手 / 会话保持。以后进入教务页自动生效。

**方式二：单独安装油猴脚本**

在 Tampermonkey 中新建脚本，粘贴 / 导入仓库根目录的 `urpppp.user.js` 内容，或直接安装该文件；设置入口同样挂在本脚本 **系统设置** 选项卡。

> 两种方式功能一致，任选其一即可，勿同时装载两套。

## 功能

### 1. 登录助手

- 教务系统登录页、统一身份认证页自动填写账号密码
- **验证码本地识别**（默认启用，零网络请求）：
  - 统一身份认证：质心模板匹配，整图识别精度 98% 以上
  - 教务系统：HSV 红色掩码提取红色字符、k-means 切割、微型 CNN 识别，整图精度约 81%、字符精度约 94%（int16 量化模型，体积约 71KB）
  - 模型训练与预处理过程参考了 [scu_ocr_lite_dart](https://github.com/The-Brotherhood-of-SCU/scu_ocr_lite_dart) 项目
- 教务验证码识别失败或低置信时，若配置了线上 OCR 服务地址则自动改用线上识别；未配置则等待手动填写
- 可选：识别后自动点击登录
- 同一次自动登录过程连续失败达到 **4 次**后暂停 OCR 与自动提交，保留已填好的学号和密码，由用户填写验证码并手动接管
- 任意一次登录成功后立即进入系统并清零；下一次自动登录过程始终从 0 开始计数

### 2. 评教助手

- 自动填写分数题 / 单选题 / 多选题 / 主观题
- 可配置：
  - 分数随机区间
  - 单选默认选项池、按题配置
  - 多选默认勾选池、按题配置
  - 主观题多行模板
- 可选「到时自动保存」：默认等待约 **100 秒** 后再提交  
  （教务侧有停留/倒计时校验，**不能**靠脚本真正跳过）

### 3. 全自动评教

在「教学评估」列表页启动后：

1. 扫描未评估问卷  
2. 逐个进入  
3. 自动填写  
4. 等待设定秒数  
5. 自动保存  
6. 返回列表继续，直到全部完成  

右下角有进度浮层，可随时停止。

## 使用

### 打开设置

1. 启用主脚本后，点顶栏 **齿轮**
2. 切换到 **系统设置** 选项卡
3. 在 **辅助插件** 区点击：
   - **登录助手**
   - **评教助手**

子面板位置与主设置窗一致。

### 登录助手配置

需要填写：

- 教务学号 / 密码
- （可选）线上 OCR 服务地址（仅本地识别失败或低置信时兜底使用）
- （可选）统一认证账密，或开启“共用账密”
- 是否持久保存密码：新安装默认关闭；已有旧密码会保留原模式，关闭开关并保存后立即清除
- 是否自动登录、提交延迟

### 线上 OCR 接口

本地识别不可用时，可配置一个符合以下约定的 OCR 服务地址作为兜底（也可留空，识别失败时手动填写验证码）：

```http
POST /api/ocr
Content-Type: application/json

{"image":"<base64 不含 data: 前缀>"}
```

期望返回：

```json
{"status":"success","code":"验证码"}
```

### 四次失败后的手动接管

- 插件只统计当前自动登录过程中，自己已经执行自动提交、随后仍回到登录页的连续失败；教务登录与统一认证使用同一账号时属于同一条重试链。单次 OCR 超时、解析失败、格式无效或组件缺失不计入登录失败。
- 第四次失败后，登录页会显示“自动登录已暂停”，并继续填好学号和密码。
- 此时插件停止 OCR、停止自动点击登录；用户只需填写验证码并手动登录。
- 可通过登录页的 **恢复自动登录**，或油猴菜单 **立即识别登录验证码** 开启一条从 0 开始的新自动登录过程。
- 成功进入教务系统后立即清零；没有上一轮自动提交标记的登录启动也会视为新过程并从 0 开始。
- 设置界面不展示运行中的失败次数；次数只在实际登录页重试期间显示。

### 评教助手配置

建议先配置：

1. 分数上下限  
2. 单选默认池（如 `A` 或 `A,B`）  
3. 特殊题按题配置（如国际周第 7 题）  
4. 多选勾选池  
5. 主观题模板（回车分隔多条，随机选用）  
6. 等待秒数（默认 100）  
7. 是否开启到时自动保存 / 全自动评教  

全自动：

1. 打开教学评估列表页  
2. 设置里点 **启动全自动评教**，或油猴菜单同名项  
3. 保持页面开启，等待逐份完成

## 风险与免责

安装或使用前请确认你理解并接受：

1. **账号与隐私风险**  
   新安装默认只保存账号，不持久保存密码；若主动开启“持久保存密码”，密码会保存在脚本管理器存储中。插件在本地识别失败且你配置了线上 OCR 服务时，才会向你配置的服务上传验证码图片。

2. **误操作 / 自动提交风险**  
   评教自动填写、自动保存、全自动评教会真实提交数据，可能产生不可撤销结果。

3. **合规风险**  
   请遵守学校教务系统使用规定与相关纪律要求。本插件仅供技术学习与个人效率参考。

4. **兼容性风险**  
   教务改版、接口变化、浏览器/脚本管理器差异都可能导致功能失效或异常。

5. **责任声明**  
   **插件可能存在风险，请谨慎安装。**  
   **使用本插件过程中出现的一切问题，请自负，作者不承担任何直接或间接责任。**

如果你不能接受以上条款，请勿安装、勿使用本辅助插件。
