## 功能

### 1. 登录助手

- 教务系统登录页、统一身份认证页自动填写账号密码
- 调用你明确配置的 OCR 服务识别验证码
- 可选：识别后自动点击登录
- 同一次自动登录过程连续失败达到 **4 次**后暂停 OCR 与自动提交，保留已填好的学号和密码，由用户填写验证码并手动接管
- 任意一次登录成功后立即进入系统并清零；下一次自动登录过程始终从 0 开始计数

### 2. 评教助手

- 自动填写分数题 / 单选题 / 多选题 / 主观题
- 可配置：
  - 分数随机区间
  - 单选默认选项池、按题配置
  - 多选默认勾选池、按题配置
  - 主观题多行模板
- 可选「到时自动保存」：默认等待约 **100 秒** 后再提交  
  （教务侧有停留/倒计时校验，**不能**靠脚本真正跳过）

### 3. 全自动评教

在「教学评估」列表页启动后：

1. 扫描未评估问卷  
2. 逐个进入  
3. 自动填写  
4. 等待设定秒数  
5. 自动保存  
6. 返回列表继续，直到全部完成  

右下角有进度浮层，可随时停止。

## 使用

### 打开设置

1. 启用主脚本后，点顶栏 **齿轮**
2. 切换到 **系统设置** 选项卡
3. 在 **辅助插件** 区点击：
   - **登录助手**
   - **评教助手**

子面板位置与主设置窗一致。

### 登录助手配置

需要填写：

- OCR 服务地址（可自建，也可明确选择下方提供的服务）
- 教务学号 / 密码
- （可选）统一认证账密，或开启“共用账密”
- 是否自动登录、提交延迟

### 可选 OCR 服务与告示

作者提供一个自行搭建的 OCR 服务：

```text
https://ocr.yanjiangrd.site/api/ocr
```

该地址已验证存在 `POST /api/ocr` 接口，但使用前必须理解：

1. 该服务是个人自建服务，**不是四川大学或教务系统官方服务**。
2. 插件向该服务发送当前验证码图片的 Base64 数据；不会在 OCR 请求中发送学号和密码。
3. 服务端仍可能接触验证码图片、请求时间、来源 IP、User-Agent 等网络元数据。
4. 服务不承诺永久可用、识别准确率或响应速度；服务异常时请关闭自动登录并手动输入验证码。
5. 填写并使用该地址即表示你自行决定将验证码图片交给该服务处理，并自行承担相关风险。

也可以填写你自己的 OCR 服务。接口约定：

```http
POST /api/ocr
Content-Type: application/json

{"image":"<base64 不含 data: 前缀>"}
```

期望返回：

```json
{"status":"success","code":"验证码"}
```

### 四次失败后的手动接管

- 插件只统计当前自动登录过程中，自己已经执行自动提交、随后仍回到登录页的连续失败；教务登录与统一认证使用同一账号时属于同一条重试链。单次 OCR 超时、解析失败、格式无效或组件缺失不计入登录失败。
- 第四次失败后，登录页会显示“自动登录已暂停”，并继续填好学号和密码。
- 此时插件停止 OCR、停止自动点击登录；用户只需填写验证码并手动登录。
- 可通过登录页的 **恢复自动登录**，或油猴菜单 **立即识别登录验证码** 开启一条从 0 开始的新自动登录过程。
- 成功进入教务系统后立即清零；没有上一轮自动提交标记的登录启动也会视为新过程并从 0 开始。
- 设置界面不展示运行中的失败次数；次数只在实际登录页重试期间显示。

### 评教助手配置

建议先配置：

1. 分数上下限  
2. 单选默认池（如 `A` 或 `A,B`）  
3. 特殊题按题配置（如国际周第 7 题）  
4. 多选勾选池  
5. 主观题模板（回车分隔多条，随机选用）  
6. 等待秒数（默认 100）  
7. 是否开启到时自动保存 / 全自动评教  

全自动：

1. 打开教学评估列表页  
2. 设置里点 **启动全自动评教**，或油猴菜单同名项  
3. 保持页面开启，等待逐份完成

安装或使用前请确认你理解并接受：

1. **账号与隐私风险**

2. **误操作 / 自动提交风险**  
   评教自动填写、自动保存、全自动评教会真实提交数据，可能产生不可撤销结果。

5. **责任声明**
